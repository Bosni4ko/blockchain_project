# Blockchain For Animal Care System

## Overview
This project is a decentralized application (**dApp**) built using Ethereum blockchain technology. The application leverages smart contracts to ensure transparency, decentralization, and security, providing a reliable system for user interactions. It uses widely adopted tools and technologies to simplify development and enhance functionality.

---

## Technology Stack

### **Frontend**
- **HTML, CSS, JavaScript, PHP**: Used to create the user interface, manage user interactions, and ensure a responsive design.
- **Web3.js**: A JavaScript library used to interact with the Ethereum blockchain and smart contracts.

### **Backend**
- **Ethereum Blockchain**: Provides the smart contract functionality required for a decentralized application. Ethereum was chosen due to its reliability, widespread adoption, and extensive tooling support.
- **Solidity**: The programming language used to develop smart contracts. It is the most popular and suitable language for Ethereum-based projects.

### **Development Tools**
- **Ganache**: A local blockchain simulator used for testing and development. It provides more control over the environment, making debugging and testing faster and easier.
- **MetaMask**: A wallet extension that supports Ethereum and other EVM-compatible chains. It allows users to manage their blockchain accounts and sign transactions seamlessly. It integrates well with JavaScript libraries like Web3.js and Ethers.js.

---

## Features
- **Smart Contracts**: Implements decentralized logic for secure and transparent operations.
- **Blockchain Integration**: Ensures data integrity and immutability using Ethereum.
- **User-Friendly Interface**: Designed with HTML, CSS, and JavaScript for a smooth user experience.
- **Wallet Support**: Integrates with MetaMask for easy account management and transaction signing.
- **Local Testing**: Uses Ganache for a controlled development environment, speeding up testing and debugging.

---

### Prerequisites
- MetaMask browser extension installed
- Ganache installed
